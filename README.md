# save91: daily savings in mutual funds, online-first, with a loan marketplace

| Folder | What is in it |
|---|---|
| [`final/`](final/README.md) | **Start here.** The current documents (the online business case, the full online plan, the LTV/CAC deck, the $0.5M seed plan, the Bachatt memo), links to the two live Google Sheets, the headline numbers read from the model, and the open items. |
| [`others/`](others/README.md) | Everything behind them: the models, tables and research, the deck builders, reviews, partner outreach, and the archived offline plan. |

`python final/make_final.py --check` says whether `final/` matches the latest builds; `python final/make_final.py` refreshes it.

**Not in the repo:** the Python environment and the raw Monte Carlo draws of the offline plan, both large (see `.gitignore`).
